# PyQuest 🐍🎮

Eine spielerische Lernplattform, die Schülerinnen und Schülern (SuS) Python-Programmierung
Schritt für Schritt beibringt – mit Gamification-Elementen wie Levels, Punkten und Quests.

## Ziel

- Python-Grundlagen niedrigschwellig und motivierend vermitteln
- Schrittweiser Aufbau: von "Hello World" bis zu kleinen Projekten
- Sofortiges Feedback beim Programmieren im Browser
- Kostenlos gehostet über [GitHub Pages](https://pages.github.com/)
